# دانلودر (Downloader) — پروژه اندروید

اپ دانلود فایل از لینک مستقیم با این قابلیت‌ها:

- **دانلود چنداتصاله (مثل IDM)**: هر فایل با ۸ اتصال موازی دانلود می‌شود تا سرعت بالاتر برود (اگر سرور از هدر Range پشتیبانی کند)
- **چند لینک همزمان**: می‌تونی یک لیست لینک (مثلاً همه اپیزودهای یک انیمه) رو یکجا پیست کنی؛ اپ همه‌شون رو تشخیص می‌ده و جداگانه دانلود می‌کنه
- دانلود در پس‌زمینه (Foreground Service) با نوتیفیکیشن پیشرفت
- لیست دانلودها با درصد پیشرفت (ذخیره در Room، با بستن اپ از بین نمی‌ره)
- Share مستقیم از مرورگر یا اپ‌های دیگه
- ازسرگیری (Resume) در حالت تک‌اتصاله اگر سرور Range داشته باشه

## نحوه ساخت APK

### روش ۱ — با Android Studio (پیشنهادی)

1. [Android Studio](https://developer.android.com/studio) را نصب کن.
2. پوشه `DownloaderApp` را با **Open** باز کن.
3. صبر کن تا Gradle Sync تمام شود (اولین بار اینترنت لازم است).
4. از منوی بالا: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
5. بعد از اتمام، روی لینک **locate** کلیک کن؛ فایل APK اینجاست:
   `app/build/outputs/apk/debug/app-debug.apk`
6. این فایل را به گوشی منتقل کن و نصب کن (باید «نصب از منابع ناشناس» را فعال کرده باشی).

### روش ۲ — از خط فرمان

```bash
cd DownloaderApp
./gradlew assembleDebug
```

APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

> اگر `gradlew` وجود نداشت، در Android Studio یک‌بار پروژه را باز کن تا wrapper کامل شود، یا از خود Android Studio بساز.

### نصب روی گوشی

- کابل USB + USB debugging و دکمه Run، یا
- انتقال فایل `app-debug.apk` به گوشی و نصب دستی.

## نحوه استفاده

1. یک لینک مستقیم وارد کن و دکمه «دانلود» را بزن.
2. یا چند لینک (هر کدام در یک خط) مثل لیست اپیزود انیمه را یکجا پیست کن — همه به صف دانلود اضافه می‌شوند.
3. از مرورگر می‌توانی لینک را با Share به این اپ بفرستی.

## محدودیت‌ها

- فقط لینک مستقیم فایل پشتیبانی می‌شود (نه یوتیوب/اینستاگرام).
- سرعت چنداتصاله وابسته به پشتیبانی سرور از HTTP Range است؛ بعضی CDNها آن را محدود می‌کنند.
